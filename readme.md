## Project Overview

This project predicts customer churn using:
- customer profile data,
- support interactions,
- broadband usage,
- payment behavior.

The goal is to help retention teams identify high-risk customers before churn occurs.

---

## Machine Learning Models

- Logistic Regression
- Random Forest Classifier

---

## Key Insights

- Out-of-contract customers show higher churn risk.
- Long support hold times correlate with dissatisfaction.
- Lower broadband usage may indicate reduced engagement.
- Frequent DD cancellations strongly relate to churn behavior.

## Project Outcome



The model successfully identifies high-risk churn customers and supports proactive retention strategies.
